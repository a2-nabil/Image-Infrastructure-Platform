# Image API v1 Contract

Baseline contract for image upload.

## `POST /api/v1/images`

Upload an image for processing and metadata extraction.

### Request

| Item | Value |
|------|--------|
| Method | `POST` |
| Path | `/api/v1/images` |
| Content-Type | `multipart/form-data` |
| Form field | `image` (required) |

#### Headers

| Header | Required | Description |
|--------|----------|-------------|
| `X-Request-ID` | Optional | Client-supplied request correlation ID. Echoed back on the response when present (or generated by the API when absent). |

### Success Response — `201 Created`

```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "fingerprint": "sha256_hash",
    "original_url": "string",
    "width": 0,
    "height": 0,
    "format": "string",
    "size_bytes": 0
  }
}
```

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Always `true` on success |
| `data.id` | string (UUID) | Image record identifier |
| `data.fingerprint` | string | SHA-256 content hash |
| `data.original_url` | string | Storage URL of the original object |
| `data.width` | number | Image width in pixels |
| `data.height` | number | Image height in pixels |
| `data.format` | string | Image format (e.g. `jpeg`, `png`, `webp`) |
| `data.size_bytes` | number | Object size in bytes |

### Error Response — `4xx` / `5xx`

```json
{
  "success": false,
  "error": {
    "code": "string",
    "message": "string"
  }
}
```

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Always `false` on error |
| `error.code` | string | Machine-readable error code |
| `error.message` | string | Human-readable error description |
